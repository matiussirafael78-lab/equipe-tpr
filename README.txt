TPR RUNNING TEAM — SITE

Arquivos:
- index.html: site completo.
- pasta imagens/: coloque logo, fotos dos uniformes e acessórios aqui.

COMO USAR:
1. Abra index.html no navegador para testar.
2. Para trocar logo/produtos/patrocinadores rapidamente, abra "Painel de edição — dono da TPR".
3. Para colocar imagens locais, use caminhos como imagens/logo.png e imagens/camiseta.jpg.
4. O formulário desta versão demonstra a inscrição no navegador. Para receber inscrições de qualquer lugar, conecte o formulário a Google Forms, Formspree, um backend ou banco de dados.
5. Os preços são exemplos e podem ser alterados.

SUGESTÃO DE PRÓXIMA ETAPA:
- publicar gratuitamente no GitHub Pages, Netlify ou serviço semelhante;
- conectar o formulário;
- colocar links de WhatsApp/Instagram;
- adicionar página de regulamento e política de privacidade.
